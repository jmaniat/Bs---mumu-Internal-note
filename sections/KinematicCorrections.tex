\section{Kinematic Corrections to Monte Carlo Samples}
\label{sec:KinematicCorrections}

The Monte Carlo samples listed in Section~\ref{sec:MCSamples} are used for various aspects of the analysis, including the evaluation of the acceptances and efficiencies in Equation~\ref{eq:BRFormula}.
In order to be accurate, various corrections are applied to the MC samples as weights for use in these computations and studies. 
The different corrections are:
\begin{itemize}
    \item  \textit{Pile Up Weights (PUWs)}: these are computed using the \verb|getCombinedWeight| function of the pile-up reweighting tool\cite{Buttinger:2014726} mentioned in Section~\ref{subsec:Triggers}. These weights correct the pile-up profile of the different MC periods to match that of data, scale the MC periods to match the relative production luminosity and account for the effect of trigger pre-scales.   
    \item \textit{Muon reconstruction scale factors (MSFs)}: these weights correct for data/MC discrepancies in muon reconstruction, as prescribed by the Muon CP group. 
    \item \textit{Trigger Scale Factors (TSFs)}: these weights account for differences between the trigger efficiencies between data and MC. \textred{At present only make sense for MC16a/2015-2016}.
    \item \textit{Quark Level Corrections (QLCs)}: the nominal MC samples are generated with quark level cuts in order to improve statistics passing the analysis selections. Such cuts can induce a bias as they change the shape of kinematic variables. The QLCs correct for this bias. The computation of the QLCs is discussed in more detail later in this section. 
    \item \textit{Data-Driven Weights (DDWs)}: these weights account for differences in the MC modelling and actual data. They are evaluated using the \BpmKpmJpsi reference channel. The procedure for computing them is also discussed in more detail in this section.  
\end{itemize}

These corrections are the same as was used in the PR2 analysis but are re-evaluated for the Full Run 2 samples. 
Additionally, the procedure for evaluating the DDWs has been revised, as detailed later in this section.  
Except for studies where it is stated otherwise, PUWs, TSFs and MSFs are always applied to all samples.
On the other hand, QLCs and DDWs are only applied to the \Bmumu, \BpmKpmJpsi and \BsJpsiPhi samples (i.e. they are not applied to the \Bhh, semi-leptonic, \bbJpsiX and \bbmumuX samples).
This is because only these samples are used to compute efficiencies and acceptances; the main purpose of the other samples is to check functional forms of different backgrounds in the signal and reference channels.

\subsection{L1-topo trigger efficiency studies}

 As introduced in Section \ref{}, L1-topo trigger was used in collecting data in 2017 and 2018. Similarly to non-topological triggers, its efficiency in data is not ensured to be well reproduced in simulation. Therefore, a technique to evaluate this efficiency in data has been developed with the goal of producing scale factors (binned in di-muon transverse momentum, pseudorapidity and angular distance??) to be applied to signal and reference channel MC samples to correct for this potential mis-modeling. \\

 \noindent
 To do that, a dedicated study was performed using data and Monte Carlo samples collected with the \texttt{bDimu} trigger. This trigger was heavily prescaled in 2017 and 2018. Nevertheless, a total of XXXXX events has been collected.
 The strategy is based on the reconstruction of \BpmKpmJpsi events in data using the dataset outlined above with the same trigger strategy used in the analysis (see Section \ref{}). An unbinned extended ML fit is performed in data to extract the \BpmKpmJpsi yield, after applying all requirements listed in Section \ref{}, except for the application of the continuum BDT requirement. Then, the same procedure is repeated on the same dataset after adding the requirement that events pass the corresponding L1-topo triggers. The ratio between the two yields represents the L1-topo trigger efficiency in data for the event selection and the trigger strategy related to this analysis. The same procedure is finally applied also to simulated \BpmKpmJpsi MC samples and the scale factors computed.
 The triggers used are the following:

 \begin{itemize}
    \item non-TOPO triggers:
    \begin{enumerate}
        \item \texttt{L1\_2mu6} and \texttt{HLT\_2mu6\_bDimu\_Lxy0}
        \item \texttt{L1\_mu6\_2mu4} and \texttt{HLT\_mu6\_mu4\_bDimu\_Lxy0}
    \end{enumerate}
    \item TOPO triggers:
    \begin{enumerate}
        \item \texttt{L1\_BPH-2M9-2MU6\_BPH-2DR15-2MU6} and \texttt{HLT\_2mu6\_bDimu\_L1BPH-2M9-2MU6\_BPH-2DR15-2MU6}
        \item \texttt{L1\_BPH-2M9-MU6MU4\_BPH-0DR15-MU6MU4} and \\\texttt{HLT\_mu6\_mu4\_bDimu\_L1BPH-2M9-MU6MU4\_BPH-0DR15-MU6MU4}
    \end{enumerate}
\end{itemize}

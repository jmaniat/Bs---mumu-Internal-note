\subsection{Triggers}
\label{subsec:Triggers}

The triggers used for the signal and reference channels are shown in Table~\ref{tab:triggers_signal} and Table~\ref{tab:triggers_reference} respectively with the recorded integrated luminosities. 
For 2015 and 2016, the triggers used are the same ones as in the PR2 analysis, while for 2017 and 2018 new triggers were developed which required topological cuts at Level-1.
This was necessary in order to maintain manageable rates with the increased instantaneous luminosity in 2017 and 2018.
For 2017 and 2018, the triggers requiring muons with \pT above 6~\GeV are active for most of the data taking, while the triggers with lower \pT thresholds were only activated towards the end of fills.
\textcolor{red}{(Also the case for 2015/2016?)} 

\textcolor{red}{Note for 2015-2016 as in PR2 we don't use HLT\_2mu6\_bBmumu\_Lxy0. Not included in PR2 due to time constraints - here I guess we just want to be consistent with PR2?.}
For Monte-Carlo, the effect of the pre-scales is handled using the pile-up reweighting tool~\cite{Buttinger:2014726} with the \verb|UseRunDependentPrescaleWeight| option set to true.
